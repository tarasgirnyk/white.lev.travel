# Лендинг із Design Handoff

Джерело: `DesignSystemHandoff/white-lev-travel-design-system/project/ui_kits/website/index.html`, отримане від власника 09.09.2026.

Збережено композицію, токени, логотип, фотографії, компоненти та галереї погодженого макета. React-компоненти збираються Next.js без браузерного Babel, CDN React та редакторських image-slot. Стилі обмежено `.handoff-landing`, щоб не змінювати каталог та адмінку.

Публічна серія — чотири Comfort для двох дорослих 18+. Тексти й тарифи беруться з актуальних словників UA/EN/PL; старі сімейні умови, площа 35–45 м² та тариф 3500 грн із прототипу не публікуються. Фото підготовлено у WebP; порожні слоти виключено. Додано мобільну верстку, FAQ з aria-expanded, справжні переходи локалей і підключення до наявної InquiryForm. Кнопка конкретного будинку вибирає його тему у формі.

Перевірки: production build, TypeScript, зображення, гортання галереї, FAQ, вибір теми у формі, зміна мови та ширина мобільної сторінки 390 px. Надсилання тестових заявок у робочу базу не виконувалось.
