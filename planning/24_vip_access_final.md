## Зафіксовані зміни

| Елемент | Рішення |
|---|---|
| Подушки | На обох ліжках білосніжні; бірюзу прибрати повністю. |
| Гардероб | Зберегти доступ із холу та майстер-спальні. |
| Майстер-санвузол | Додати двері з гардероба до суміжного санвузла; не перекривати прохід сантехнікою. |
| Зайва шафа | Прибрати окрему шафу вздовж верхньої стіни майстер-спальні. |
| Вихід зі спальні | Розсувні скляні двері на терасу. |
| Вихід із вітальні | Окремі розсувні скляні двері на терасу з вільним підходом. |
| Телевізор | На лівій стіні вітальні навпроти дивана, поруч із каміном у бік тераси. |
| Гостьовий санвузол | Розширити праворуч до зовнішньої стіни, використавши порожню смугу; вхід із вітальні. |
| Сауна | Розширити ліворуч у нішу, вирівнявши її ліву стіну зі стіною гостьового санвузла; вхід із вітальні. |

## Маршрути

- Вхід → хол → гардероб; вітальня → майстер-спальня → гардероб → приватний санвузол.
- Майстер-спальня → власні скляні двері → тераса.
- Вітальня → друга спальня / гостьовий санвузол / сауна.
- Вітальня → окремі скляні двері → тераса.

## Збережені рішення

Гірчичні м’які меблі, сірі лофтові стіни, камін зліва, диван до каміна, журнальний столик, кухня та центральний обідній стіл. На терасі — барбекю, джакузі, круглий стіл і чотири лежаки.
