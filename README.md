# White.Lev.Travel · «Білий Лев»

Заміський комплекс приватних будинків для відпочинку — урочище «Варуш», с. Явора, Турківщина, Львівщина.
Модель: будуємо і продаємо будинки інвесторам як дохідні активи (Сценарій A: 2×Compact + Comfort + VIP).

## Структура

Поточний новий напрям: [Green Love Travel — тематична серія Compact](planning/25_green_love_compact_series.md). 3–4 однакові будівельні основи з різними інтер’єрами; будинок №1 — **«Адам і Єва»**, для двох дорослих без дітей. Назву, білий і червоний кольори та дзеркальні акценти задав власник. Другий будинок — «Пікассо», творчий арт-інтер’єр із клубним характером. Третій будинок — «Max Royal», за наданими фото інтер’єрів Maxx Royal Kemer. Тема можливого №4 і точна кількість попередні. Нижчі рівні Room і Mini — перспектива розширення лінійки.
