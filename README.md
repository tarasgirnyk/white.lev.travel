# White.Lev.Travel · «Білий Лев»

Поточна концепція Green Love Travel — **чотири тематичні Comfort, кожен тільки для двох дорослих, 18+**. Без дітей, додаткових гостей і спальних місць. Спільна невелика будівельна основа, необхідне оснащення, доступне виконання й чотири виразні інтер’єри.

## Локація й модель

Урочище «Варуш», с. Явора, Турківщина, Львівщина — тихе Прикарпаття / Бойківщина. Дві суміжні ділянки приблизно 0.44 га. Продуктова програма — 4×Comfort, до 8 дорослих; точна посадка перевіряється генпланом. Модель — будівництво та продаж інвесторам із можливістю управління орендою й сервісом.

Доступний бюджет — ціль; площі, ціни, тарифи й дохідність ще не затверджені. Старі показники сімейного Comfort не використовуються для цієї серії.
