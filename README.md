# White.Lev.Travel · «Білий Лев»

Заміський комплекс приватних будинків для відпочинку — урочище «Варуш», с. Явора, Турківщина, Львівщина.
Модель: будуємо і продаємо будинки інвесторам як дохідні активи (Сценарій A: 2×Compact + Comfort + VIP).

## Структура

- **`КОНЦЕПЦІЯ_БУДІВНИЦТВА_WHITE_LEV_TRAVEL.md`** — головний концептуальний документ
- **`reference.txt`** — референси стилю будиночків
- **`planning/`** — робочі етапи проєкту:
  - `01_site_analysis.md` — аналіз ділянки
  - `02_concept_masterplan.md` + `02_masterplan_scheme.svg` — концепція та генплан
  - `03_budget_economics.md` — кошторис та економіка
  - `04_market_monitor.md` — моніторинг ринку
  - `05_finance_model.xlsx` — фінансова модель
  - `06_architecture_brief.md` — архітектурне ТЗ (Compact/Comfort/VIP)
  - `07_masterplan_overlay.png` (+ `.html`) — схема розміщення поверх аерознімка
  - `08_house_types_concept.png` (+ `.html`) — концепт-лінійка будиночків
- **`documents/`** — правові документи (будпаспорт, витяг, договір, рішення сільради)
- **`photo_drone/`** — аерознімки ділянки з дрона
- **`places/`** — кадастрові скріншоти ділянок (`:0002` my, `:0001` misha)
